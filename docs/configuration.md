# Configuration Reference

| Variable | Type | Default | Description |
|---|---|---|---|
| `ZENITH_MAX_WORKERS` | int | `16` | Maximum worker threads in pool |
| `ZENITH_QUEUE_CAPACITY` | int | `10000` | Task queue buffer size |
| `ZENITH_HEARTBEAT_INTERVAL` | float | `1.0` | Health check interval in seconds |
